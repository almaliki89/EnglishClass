# منصة أوميغا التعليمية (OMEGA Platform) • منهج اللغة الإنكليزية العراقي

منصة تعليمية متكاملة للمنهج العراقي الرسمي لمادة اللغة الإنكليزية للمراحل المتوسطة والإعدادية (إشراف الأستاذ مصطفى تركي):
- **الأول المتوسط** (First Intermediate) - امتحانات مدرسية نهائية.
- **الثاني المتوسط** (Second Intermediate) - امتحانات مدرسية نهائية.
- **الثالث المتوسط** (Third Intermediate) - تحضير للامتحان الوزاري بنسبة نجاح 100% ومحاكي 100 درجة.
- **الرابع الإعدادي** (Fourth Preparatory) - امتحانات مدرسية نهائية ونصوص أدبية.
- **الخامس الإعدادي** (Fifth Preparatory) - امتحانات مدرسية نهائية.
- **السادس الإعدادي** (Sixth Preparatory) - البكالوريا الوزارية الشاملة (طبعة 2024-2026 الرسمية حصراً: عمار والهيكل الخارجي، نجلة عماد لفتة، راشد ورنا للأزياء، نهر الفرات، كبرياء وتحامل لجين أوستن، كما تحب لوليم شكسبير).

---

## 🏗️ البنية التقنية (Architecture)

1. **الواجهة الأمامية (Frontend):**
   - React 19 + TypeScript + Vite + Tailwind CSS.
   - دعم كامل للغة العربية (RTL) مع إبراز الجمل والمفردات الإنكليزية (LTR).
   - توجيه كامل عبر React Router مع سلامة الروابط العميقة (`/grade/:gradeId`, `/lesson/:lessonId`, `/curriculum`, `/mock`, `/exam`, `/review`).

2. **الخادم ونقاط الـ API (Backend):**
   - Express 4 + Node.js (المنفذ: 3000).
   - أمن المدخلات: جدار عزل هيكلي للمستندات غير الموثوقة `<<<UNTRUSTED_CURRICULUM_DOCUMENT_START>>>` لمنع هجمات حقن التوجيهات (Prompt Injection).
   - استخراج وتدقيق صفحات الـ PDF والتحقق من التوقيع الرقمي `%PDF` وحساب بصمة SHA-256 لاكتشاف النسخ المكررة.
   - كشف الملفات المصورة التي تحتاج OCR وتصنيفها كـ `needs_ocr` دون اختلاق بيانات وهمية.
   - مساعد ذكي منضبط (Strict Grounded RAG) يستشهد بأرقام الصفحات والوحدات حصراً.

3. **قاعدة البيانات والأمان (Firebase Firestore & Auth):**
   - عزل تام لبيانات الطلاب (`/students/{studentId}`) بحيث لا يمكن لأي طالب قراءة أو تعديل بيانات حساب آخر.
   - إدارة المناهج (`/curriculum_sources`): قراءة عامة للطلاب ومصادر المناهج المعتمدة، مع حظر الكتابة إلا للمشرفين المخولين.

## 🚀 التشغيل والاختبار

### المتطلبات:
- Node.js 20+

### التثبيت والتشغيل:
```bash
npm install
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### فحص واختبار المنظومة:
```bash
npm run test:acceptance
```
يشمل:
- فحص الأنواع الصارم: `tsc --noEmit`
- جناح اختبارات المناهج والعزل والأمن: `tsx scripts/verify_english_curriculum.ts` (464+ تأكيد نجاح)
- البناء للإنتاج: `vite build && esbuild server.ts`
